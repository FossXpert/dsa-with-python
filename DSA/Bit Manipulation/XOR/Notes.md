1. Core Properties
* Self-Inverse: 
Applying the XOR operation with the same value twice cancels it out. If you take a number $A$ and XOR it with $B$, and then XOR the result with $B$ again, you get $A$ back:$$(A \oplus B) \oplus B = A$$
* Self-Inverse: $x \oplus x = 0$
* Identity: $x \oplus 0 = x$
* Commutative & Associative: Order does not matter.Reversibility: If $a \oplus b = c$, then $a \oplus c = b$ and $b \oplus c = a$.
